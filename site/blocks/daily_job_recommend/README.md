# 일일 직업 추천 블록

일반고 학생 대상 포털 상단에 매일 바뀌는 해양 직업을 소개하는 디디쌤 코드블럭.
상세 요구사항: `/Users/sirius/DIVE 2026/일일직업추천블록_구현지시.md` (레포 밖, 커밋 금지)

## 빌드 방법

1. 레포 루트에 `.env` 파일이 있는지 확인 (`WORKNET_API_KEY=...`). 없으면 `.env.example` 참고해서 생성.
2. 빌드 실행:
   ```bash
   python3 site/blocks/daily_job_recommend/build.py
   ```
3. `dist/daily_job_block.html`이 생성됨. **이 파일 전체를 복사해서 디디쌤 코드블럭에 붙여넣기.**
   (자동 배포 아님 — 항상 수동으로 붙여넣어야 함)

`dist/`는 실제 API 키가 그대로 박혀서 나오는 결과물이라 `.gitignore`에 포함되어 있음.
소스 수정 후에는 반드시 다시 빌드해서 최신 파일을 붙여넣을 것.

## 현재 상태 (2026-07-25)

- **워크넷 오픈API 실제 연동 완료. mock 데이터 없음.**
  - 검색(목록): `callOpenApiSvcInfo212L50.do` — 직업명 → 직업코드(dJobCd)
  - 상세: `callOpenApiSvcInfo212D01.do` — dtlGb=1(요약) + dtlGb=3(교육/자격/훈련)로 필드 대부분 채움
  - 둘 다 실제 authKey로 curl 검증 완료. 브라우저 콘솔에서 네트워크 탭으로 실호출 확인 가능.
- **API에 대응 필드가 없는 항목**: "유사 명칭", "경력" — 항상 폴백 문구("데이터 준비 중")로 표시됨.
  워크넷 KNOW 데이터 자체에 없는 필드라 UI 버그 아님.
- **직업에 따라 상세 데이터가 비어있을 수 있음** (예: 도선사 일부 필드) — 실제 정부 데이터의 한계이며,
  각 필드가 개별적으로 "데이터 준비 중"으로 폴백되도록 이미 처리되어 있음.
- **화이트리스트는 현재 2개(해양경찰관, 선박기관사)뿐임.** 해양 관련 키워드 160개+로 실직업코드를
  전수조사한 결과, 하는일/임금/전망/만족도/능력/지식까지 다 채워진 진짜 해양 직업이 이 2개뿐이었음
  (도선사·항해사 등 대부분의 세분화된 해양 직업은 워크넷 KNOW 상세 통계 자체가 비어있음 — 정부
  데이터셋의 실제 한계). 값이 채워진 직업을 더 찾으면 `data/ocean_jobs_whitelist.json`에 추가.
- 오늘의 직업은 하루 고정이 아니라 **새로고침할 때마다 화이트리스트에서 무작위로 선택**됨.
- 관련 학과 → 개설 대학 → 필요 교과·역량 연결(커리어넷 학과정보 API)은 이슈 #2의 다음 단계 —
  "관련 학과 자세히 보기" 버튼은 지금은 안내 alert만 뜸.
- Step 3(챗봇) 연동은 `window.sncAskChatbot(jobNm)`을 전역에 정의해두면 자동으로 연결됨.

## 파일 구조

- `src/template.html` — 실제 작업 파일 (커밋 대상)
- `data/ocean_jobs_whitelist.json` — 오늘의 직업 로테이션 대상 목록
- `build.py` — 위 파일들을 합쳐 `dist/daily_job_block.html`을 생성하는 스크립트 (표준 라이브러리만 사용)
